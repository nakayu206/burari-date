# ぶらりデートガチャ 環境構築手順

> 新しいPC・新メンバー参加時の初期セットアップ手順。上から順に実行すれば動かせる状態になる。

---

## 0. 前提

| 項目 | バージョン |
|---|---|
| OS | Windows 10/11 または macOS |
| Flutter | 3.41.x以上 |
| Dart | 3.11.x以上(Flutter同梱) |
| Android Studio | 最新安定版 |
| Xcode | 最新安定版(macOSのみ) |
| VS Code | 最新版(推奨エディタ) |

---

## 1. Flutter SDKのインストール

### Windows

1. [Flutter SDK](https://docs.flutter.dev/get-started/install/windows) をダウンロード
2. `C:\src\flutter` などに展開(パスにスペース・日本語は禁止)
3. 環境変数`Path`に`C:\src\flutter\bin`を追加
4. 確認: `flutter --version`

### macOS

```bash
brew install --cask flutter
flutter --version
```

---

## 2. Android開発環境

### 2-1. Android Studioをインストール

[Android Studio公式](https://developer.android.com/studio) からインストーラーを取得して実行。
初回起動時のセットアップウィザードでAndroid SDK / SDK Platform / Android Virtual Deviceを入れる。

### 2-2. ライセンス同意

```powershell
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
flutter doctor --android-licenses
```

すべて`y`で同意する。

### 2-3. エミュレータ作成(AVD)

Android Studioの `More Actions` → `Virtual Device Manager` → `Create Device` でPixel 6 / API 34
等を選択して作成する。

---

## 3. iOS開発環境(macOSのみ)

```bash
sudo xcode-select -s /Applications/Xcode.app
sudo xcodebuild -license

brew install cocoapods
pod setup
```

> `sudo gem install cocoapods` は使わないこと。macOS標準のRubyは古く、CocoaPodsが依存する
> `ffi`がRuby 3.0以上を要求するためインストールに失敗する。必ずHomebrew経由でインストールする。

> Windowsユーザーは iOS ビルドをスキップしてOK(Macで別途実施)。

## 4. VS Codeセットアップ

### 4-1. 必須拡張機能

| 拡張 | 用途 |
|---|---|
| Flutter | デバッグ・補完・ホットリロード |
| Dart | Flutterに同時インストールされる |

```powershell
code --install-extension Dart-Code.flutter
```

### 4-2. 推奨設定

`.vscode/settings.json`(リポジトリ内に作る場合):

```json
{
  "editor.formatOnSave": true,
  "editor.codeActionsOnSave": {
    "source.fixAll": "explicit",
    "source.organizeImports": "explicit"
  },
  "[dart]": {
    "editor.rulers": [80],
    "editor.selectionHighlight": false,
    "editor.suggestSelection": "first",
    "editor.tabCompletion": "onlySnippets"
  }
}
```

## 7. 外部API・バックエンドについて

駅・路線データはHeartRails Express、グルメ検索はホットペッパー、観光検索はFoursquare、候補の要約はClaude APIを使う。
外部APIの呼び出しは、Firebase Functions(`functions/`)の`getCandidates`が行い、アプリからは呼ばない(APIキーをアプリに入れないため)。
履歴・お気に入り・利用回数は、Firestoreに保存する。

### 7-1. お問い合わせメール(`sendInquiry`)の設定

アプリ内の問い合わせフォームは、`sendInquiry`がResend経由で運営者のメールに送る(Issue #119)。
APIキーと受信先のメールアドレスは、リポジトリに入れず、Firebaseの Secret に登録する。

1. [Resend](https://resend.com/)のアカウントを、受信したいメールアドレスで作り、APIキーを発行する
   (独自ドメインがない間は、差出人がResendのテスト用アドレスになり、登録したアドレスにだけ届く)
2. Secretを登録する(値は、実行後の入力画面で貼る)

```bash
firebase functions:secrets:set RESEND_API_KEY --project burari-date
firebase functions:secrets:set INQUIRY_TO_EMAIL --project burari-date
```

3. デプロイする: `firebase deploy --only functions --project burari-date`

Secretが未登録のままデプロイすると、入力を求められて止まる。先に登録すること。

## 8. トラブルシューティング

### `JAVA_HOME`が設定されていない

```powershell
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
```

### `flutter pub get`が遅い・失敗する

```powershell
flutter clean
flutter pub get
```

### `flutter analyze`でエラー

```powershell
dart fix --apply       # 自動修正
dart format .          # フォーマット
```
