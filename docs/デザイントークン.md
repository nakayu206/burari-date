# デザイントークン

> マジックナンバー禁止。数値・色を直書きせず、必ず定数(`lib/core/constants/`)を経由する。
> 実装: [app_colors.dart](../lib/core/constants/app_colors.dart), [app_spacing.dart](../lib/core/constants/app_spacing.dart), [app_sizes.dart](../lib/core/constants/app_sizes.dart)

## デザイン方針

- **トーン**: 昭和レトロPOP。ベンガラ色・生成り色を基調にした、あたたかく懐かしい雰囲気
- **出典**: [Figmaデザイン案](https://www.figma.com/design/1zNLU0L3FyTI4IXodCTtog)(全8画面)から抽出

## カラー

| トークン名 | カラー | 用途 |
|---|---|---|
| primary | `#B23A1E`(ベンガラ色) | 主要ボタン・アクセント |
| primaryLight | `#FBF3DE` | 入力欄・カードの淡い背景 |
| secondary | `#2E6B5E`(差し色) | 検索欄の枠・候補カードの枠 |
| background | `#F2E6C9` | 画面全体の背景 |
| surface | `#FFFFFF` | S-02bの検索入力欄など |
| textPrimary | `#2E2115` | 見出し・濃いテキスト、枠線 |
| textSecondary | `#8A5A2E` | サブテキスト |

## スペーシング

`xs=4 / sm=8 / md=12 / lg=16 / xl=20 / x2l=24 / x3l=32 / x4l=40 / x5l=48 / x6l=64`

## コンポーネントサイズ

- buttonHeight: 48.0
- inputHeight: 44.0(入力欄・検索欄)
- bottomNavHeight: 65.0
- iconSm/Md/Lg: 16 / 20 / 32

## 角丸(BorderRadius)

- radiusSm: 6.0(ボタン・入力欄)
- radiusMd: 8.0(カード)
- radiusLg: 20.0(モーダルシート等)

## タイポグラフィ

- Noto Sans JP(Bold/Regular)を`google_fonts`パッケージ経由で使用
- フォントサイズは[app_font_sizes.dart](../lib/core/constants/app_font_sizes.dart)を経由する(マジックナンバー禁止)

| トークン名 | サイズ | 用途 |
|---|---|---|
| displayLarge | 34px | ロゴ(S-01)・到着駅名(S-04) |
| headlineLarge | 24px | ガチャ演出キャプション大(S-03) |
| titleMedium | 16px | 候補詳細の店名(S-06) |
| buttonLabel | 15px | 主要ボタンのラベル |
| bodyLarge | 14px | 本文標準・入力文字 |
| bodyMedium | 13px | 本文小・サブキャプション |
| labelSmall | 11px | 入力欄のラベル等 |
| caption | 10px | ボトムナビラベル・徒歩分数・日付 |
| footnote | 9px | 画面最小の注意書き |
